Diferencia entre int y double



int: Se usa para contar cosas completas que no se dividen, como la cantidad de personas en el viaje. No lleva decimales.



double: Se usa para medir cosas precisas que llevan centavos o fracciones, como el precio del galón o los kilómetros recorridos.



¿Qué es el casting?

Es forzar a un dato a cambiar de tipo cuando C# no lo hace solo. Por ejemplo, si tienes un valor en decimales y necesitas pasarlo a entero, haces un casting para decirle al código que ignore la parte decimal y se quede solo con el número base.



¿Cuándo se usa % (Módulo)?

No saca porcentajes. Se usa para obtener el residuo de una división (lo que sobra). Sirve principalmente para saber si un número es par o impar (viendo si el residuo es cero) o para repartir segundos sobrantes en minutos y horas.
