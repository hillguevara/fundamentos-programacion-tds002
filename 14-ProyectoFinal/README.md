La Repostería de Hill — Sistema de Gestión de Inventario

Este proyecto es el trabajo final del curso. Consiste en una aplicación de consola en C# para gestionar el inventario, ventas y reportes de "La Repostería de Hill".

Funcionalidades Principales

1. Agregar Producto: Permite registrar nuevos productos ingresando nombre, precio y cantidad.
2. Ver Inventario: Muestra la lista completa de productos registrados con su precio y stock disponible.
3. Vender Producto: Permite realizar ventas buscando por nombre, validando y descontando el stock correspondiente.
4. Reporte de Inventario Bajo: Muestra una alerta con los productos que tienen menos de 5 unidades en existencia.
5. Valor Total del Inventario: Calcula de forma acumulada el valor financiero total del inventario disponible (`precio * cantidad`).

Tecnologías Utilizadas

Lenguaje: C# (.NET Core / Console Application)
Estructuras de datos: Listas genéricas (`List<T>`)
Control de versiones: Git & GitHub
